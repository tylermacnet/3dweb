Static sample — singleton source

Static test-src/sample/listingFeeds.xml is inlined at build time (works file://) and loaded into the browser-level lazy singleton getListingStore(document). All listing-grid views read from it. Refresh swaps the singleton from static to live feed.

Filters — separated

listing-filters — controls all views

Separated from the view sections. Writes to the singleton store; every listing-grid that is active (its <details> open) re-renders with filtered results. Collapsed views stay dormant via content-visibility and update on next open.
